# Local-First SQLite & Hybrid Vector Database Sync Engine

A cross-platform (Windows / Linux / Android-Termux) sync engine with automated licensing via Lemon Squeezy and Cloudflare Tunnel routing.

## 🚀 Features
- **Local-First Architecture:** High-performance local SQLite data persistence.
- **Hybrid Vector Database:** Real-time semantic search and vector cache sync.
- **Automated Monetization:** Flask Webhook listener integrated with Lemon Squeezy.
- **Instant Licensing:** Automated `PRO-XXXX` license key generation upon purchase.
- **Global Secure Routing:** Cloudflare Tunnel (`ai-sync-tunnel`) configuration for local endpoints.

## 📦 Project Structure
- `src/ai_local_engine/` - Core database engine, vector store, and webhook server.
- `tests/` - Automated unit and integration tests.
